# Observatório de Mercado Imobiliário — Estudos Preliminares de Interface

## 1. Sobre o projeto

Este repositório reúne estudos preliminares de interface para o Observatório de Mercado Imobiliário da Secretaria do Patrimônio da União (SPU).

O objetivo é explorar possibilidades de organização e visualização de informações do mercado imobiliário, considerando funcionalidades como consulta, filtragem, análise comparativa e visualização de dados.

As telas apresentadas neste repositório têm caráter **exploratório e demonstrativo**, com foco na representação visual de possíveis interfaces para a aplicação. Não representam necessariamente o produto final nem implicam a implementação de funcionalidades completas.

## 2. Referências de design

O desenvolvimento visual das telas utiliza como referência o Design System do Governo Federal, buscando manter consistência com os padrões de interface, componentes e diretrizes de design adotados no contexto de serviços digitais governamentais.

- **Figma — Componentes do Design System:** https://www.figma.com/team_invite/redeem/aAeEq3hMyEHqIdGw1CLX3J?t=KKCV3CgVcPJG81h0-21

## 4. Como executar o projeto localmente

Para visualizar as telas no ambiente local, siga os passos abaixo.

### 4.1. Baixar o código

Clone o repositório utilizando o comando abaixo, substituindo `URL_DO_REPOSITORIO` pelo endereço deste repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Em seguida, entre na pasta do projeto:

```bash
cd NOME_DA_PASTA
```

Alternativamente, é possível baixar o código em formato ZIP pela opção **Code → Download ZIP**, na página do GitHub, e extrair os arquivos no computador.

### 4.2. Instalar as dependências

Dentro da pasta do projeto, execute:

```bash
npm install
```

Esse comando instala as dependências necessárias para executar a aplicação.

### 4.3. Executar o ambiente de desenvolvimento

Após a instalação, execute:

```bash
npm run dev
```

O terminal exibirá um endereço local, geralmente semelhante a `http://localhost:5173/`.

Abra o endereço informado no navegador para visualizar as telas.

Para encerrar a execução, volte ao terminal e pressione `Ctrl + C`.

## 5. Observações

- Este projeto tem finalidade exclusivamente demonstrativa e exploratória.
- As telas não representam necessariamente a versão final da aplicação.
- Os dados apresentados devem ser considerados ilustrativos, salvo indicação em contrário.
- A execução local depende das tecnologias e das dependências configuradas no projeto.
- As decisões de interface poderão ser revistas conforme o avanço dos estudos e o alinhamento com os requisitos do projeto.
